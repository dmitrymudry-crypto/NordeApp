# NordeApp 0.4 — реализация и QA

Дата: 14 октября 2026. Ветка `feature/ux-bath-configurator-20261014`, основана на экспериментальной ветке `feature/bad-preisrechner-demo-20261014` (PR #1). Production/default-ветка и GitHub Pages не изменяются.

## Основные изменения

Конфигуратор из длинного списка превращён в шесть шагов. Его состояние поднято в оболочку приложения; навигация назад и переход к форме не теряют комплектацию. Визуальные варианты сантехники, нейтральные фактуры и оригинальная SVG-иллюстрация поддерживают выбор. Иллюстрация показывает душ/ванну, один или двойной умывальник, свет зеркала, оттенки и форматы плитки. На десктопе сводка закреплена рядом с выбором; на телефоне отображаются цена и переход к следующему шагу.

Расчёт использует один каталог. Убрана демонстрационная наценка за обычную ванну, поскольку стандартная ванна или душ входят в подтверждённый пакет. Демонстрационный +350 € за радиатор теперь явно обозначен как разница за дизайн-обновление, а не второй платёж за стандартный радиатор. LED-зеркало в двух разделах — одна опция. Цена неизвестной или недостоверно оцениваемой конфигурации не подменяется точной суммой.

Вместо ошибки при офлайн-отправке форма теперь сохраняет локальную демо-заявку. Она не обращается к API, не отправляет почту и не заявляет о получении запроса компанией. Полная конфигурация передаётся автоматически, фотографии показываются до отправки, контактные поля и фотографии остаются при возврате к подбору. Для существующих клиентов сохранены проектные экраны и отдельная консультация в кабинете. Демонстрационный inbox использует только локальные записи.

Типографика увеличена, текстовые цвета усилены. Большие экраны используют доступную ширину. Основное меню состоит из четырёх действий; игра сохранена в профиле. Добавлены мягкие переходы, обратная связь при изменении цены, фокус заголовка нового шага, skeleton при загрузке и поддержка reduced motion. Escape в модальном окне теперь использует актуальный callback.

## Выполненные проверки

- `npm test`: 22 теста, все прошли. Включают существующий интеграционный API-сценарий и новую симуляцию, арифметику, согласие, сохранение полной конфигурации и отсутствие сетевой доставки.
- `npm run build:offline`: production-сборка и экспорт автономного HTML прошли.
- Python Playwright + Chromium, `tests/frontend-smoke.py`: старт без аккаунта; база 12 949 €; добавление/снятие нескольких опций; ванна без повторной доплаты; >6 м² и индивидуальные конфигурации; неверная площадь; сохранение выбора назад/вперёд и после reload; перенос в форму; проверка телефона; preview фото; локальное подтверждение; local inbox; просмотр счёта существующего демопроекта; мини-игра.
- Размеры 360, 390, 768, 1440 px: без горизонтального overflow. Проверена смена мобильной закреплённой цены на постоянную desktop-сводку.
- В тестовых сценариях не зарегистрированы runtime page errors. Загрузка HTML и локального blob фото — единственные запросы; API и внешние сетевые вызовы отсутствуют.
- axe-core: WCAG 2 A/AA и 2.1 AA на приветствии, площади, материалах, сводке, форме, подтверждении и документах проекта. После исправления контраста прогресса/активной вкладки и фокуса прокручиваемых этапов — 0 найденных нарушений. Результат: `docs/screenshots/v0.4/accessibility.json`.

## Ограничения

Тесты выполнялись в Chromium с мобильным viewport и touch, не на физическом iPhone. Safari/WebKit, VoiceOver, реальные клавиатуры iPhone, offline storage quotas и реальный продуктовый каталог отдельно не сертифицированы. Автоматический audit не доказывает полное соответствие всем WCAG-критериям.

Цвета/материалы являются пожеланиями и иллюстрациями, не обещанием конкретного товара или разрешением считать все варианты коммерчески равноценными. Приложение не выполняет инженерную проверку. Демонстрационные цены требуют согласования. Настоящие фотографии ванных остаются следующим контентным шагом.
