# NordeApp · Design demo 0.4

Клиентское приложение для консультации по ремонту ванной и сопровождения проекта. Интерфейс на немецком языке, React + Vite. Текущий этап — дизайн, frontend и локальная демонстрация. Никакой публикации, отправки писем или настройки production-инфраструктуры в этой итерации.

## Что смотреть

- Одно короткое приветствие: можно сразу начать подбор ванной или перейти к обзору.
- Четыре основных раздела: Start, Bad konfigurieren, Meine Projekte, Profil. Игра находится в профиле.
- Визуальный конфигуратор из шести шагов: площадь; душ/ванна; WC/умывальник/зеркало; цвет/формат/поверхность плитки; комфорт; сводка.
- Иллюстративная ванная реагирует на выбранные компоненты и материалы. Это оригинальная графика, не фотографии выполненных компанией объектов и не инженерная планировка.
- Цена меняется сразу. 12 949 € brutto — подтверждённая база до 6 м². Обычная ванна или душ, стандартная сантехника и радиатор не оплачиваются повторно; доплаты — исключительно примеры для демо. Для >6 м², душа вместе с ванной, двойного умывальника и крупноформатной плитки — индивидуальный расчёт, без точной выдуманной суммы.
- Калькуляция и выбор сохраняются при навигации и обновлении страницы. Выбор LED-зеркала в сантехнике и дополнительных опциях синхронизирован и не начисляется дважды.
- Без регистрации: короткая форма, автоматическая сводка конфигурации, до трёх фотографий, локальное подтверждение с явной пометкой, что реальная отправка не выполнялась.
- Демонстрационный кабинет команды в профиле показывает локальные заявки; можно менять их демонстрационный статус. Существующие проекты, документы, счета, отзывы и игра сохранены.
- На телефоне — нижнее меню и закреплённая цена. На планшете — более широкие карточки. На компьютере — две колонки с постоянной сводкой.

## Открыть без установки зависимостей

В `web-demo/index.html` находится автономная версия, включающая скрипты, стили и иллюстрации. Откройте файл в браузере на компьютере. В архиве `artifacts/Norde-Web-Design-Demo.zip` этот же файл называется `Norde-Demo.html`.

Safari на iPhone обычно не запускает скачанный HTML как полноценную страницу. Для локальной проверки с телефона можно открыть эту версию с компьютера в одной Wi-Fi сети:

```sh
python3 -m http.server 8000 --bind 0.0.0.0 --directory web-demo
```

На телефоне в Safari введите `http://<локальный-IP-компьютера>:8000`. Это локальная проверка на вашей сети; публичная публикация не требуется. Компьютер должен оставаться включён, а его firewall должен позволять выбранный локальный порт. При недоступности Python используйте установленный локальный статический сервер. Предыдущий публичный GitHub Pages остаётся прежней версией: эта итерация туда не опубликована.

Данные демо хранятся только в браузере данного устройства. Используйте вымышленные контакты и фотографии для тестов. Вход симулируется, пароли не сохраняются. Если браузер запрещает локальное хранилище, интерфейс работает в памяти до закрытия страницы. Смена устройства не переносит данные.

## Сборка

Node.js 24+, Python 3 для экспорта единого HTML:

```sh
npm ci
npm run build:offline
```

Результаты: `dist/` и `web-demo/index.html`. `scripts/export-offline.py` не обновляет Xcode/iOS и не публикует сайт. `npm run dev` запускает Vite для разработки; для автономной демонстрации используйте собранный HTML. Существующий server.mjs в этой итерации не менялся; экспериментальная ветка PR #1 содержит его более ранние изменения. Для исследования работы серверной версии остаются команды `npm run dev:server`, `npm run demo` и `npm start`, но для текущего frontend-просмотра они не требуются.

## Проверки

```sh
npm test
npm run build:offline
```

22 теста проверяют существующий API, валидатор, расчёт, исключение повторных начислений, индивидуальные расчёты и локальную симуляцию заявок. Браузерный smoke-тест использует Python Playwright и установленный Chromium:

```sh
python3 -m http.server 3095 --bind 127.0.0.1 --directory web-demo
# В другом терминале:
python3 tests/frontend-smoke.py --url http://127.0.0.1:3095/
```

При наличии axe-core можно передать `--axe /path/to/axe.min.js`. Зависимость не добавлена в приложение. Тесты и снимки экрана описаны в [QA-отчёте](docs/design-0.4-qa.md). Автоматический аудит не является сертификатом полного соответствия WCAG или заменой тестов на физическом iPhone.

## Данные и решения

Все цены находятся в `src/pricing.js`; каталоги материалов и вариантов — в `src/bathroom-options.js`. Доплаты за LED-зеркало, тёплый пол, дизайн-радиатор, потолок со светом и подключение стиральной машины перенесены из экспериментальной версии и всё ещё **не согласованы для продажи**.

Требуют подтверждения: окончательные доплаты и список стандартной комплектации, конкретные продукты, настоящие фотографии готовых ванных с правом использования. Просмотренная галерея официального сайта содержала фасады, общестроительные объекты и обычный интерьер; они не использованы как фотографии ванных. Никакие исходные PDF заказчиков или их личные данные в приложение не добавлены.

Сервер, размещение, почта, оплаты, реальная авторизация и App Store находятся за рамками текущей задачи. Xcode-проект и архив iOS в репозитории относятся к предыдущему прототипу.
