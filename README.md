# Norde · Mein neues Bad

Первый рабочий веб-прототип клиентского приложения Norde Development. Интерфейс на немецком языке, адаптирован под телефон и компьютер. Сервис соединяет консультацию по ремонту ванной и сопровождение проекта.

## Запуск

Требуется Node.js 24+. В каталоге `/workspace/NordeApp`:

```sh
npm ci --cache /workspace/.npm-cache
npm run build
npm run demo
```

Сервер использует порт 3000 и по умолчанию слушает только loopback. В браузере на **той же машине** откройте адрес сервера на этом порту. Этот адрес не является публичной ссылкой и с телефона вне машины недоступен. Для внешнего доступа потребуется развёртывание с HTTPS или поддерживаемый платформой проброс порта.

Нажмите «Demo ausprobieren», чтобы войти демонстрационным клиентом. «Team-Demo öffnen» переключает на демонстрационного администратора. Эти кнопки доступны исключительно при `NORDE_DEMO=1`; **не включайте этот режим на публичном сервере**. Данные демонстрации полностью вымышлены. Регистрация собственного тестового клиента также работает.

Для разработки интерфейса запустите в двух терминалах:

```sh
npm run dev:server
npm run dev
```

Vite на порту 5173 проксирует API на 3000. SQLite, фотографии и PDF хранятся в игнорируемом каталоге `.data/`, данные переживают перезапуск. `NORDE_DATA_DIR` позволяет выбрать другую директорию. Не удаляйте существующую базу при повторной настройке. Приватные документы заказчиков не входят в код или демонстрационные данные.

## Что работает

- Регистрация и вход по email/паролю, scrypt-хеширование паролей и HttpOnly-сессия.
- Четыре шага Beratung: контакт/адрес/площадь/число ванных/фото; работы и пожелания; комплектация и дата; проверка и согласие.
- Комплект из объявления: 12 949 € за ванную до 6 м², материалы и оборудование включены. Технические условия и исключения показаны в описании. Это запрос на консультацию, не автоматическое коммерческое предложение.
- Essential и Signature — предварительные названия альтернатив без неподтверждённых цен. Для нескольких ванных или площади свыше 6 м² — индивидуальный расчёт.
- Клиент видит только собственные проекты; команда — все заявки. Администратор обновляет статус, прогресс и сроки, публикует заметки с фото, загружает PDF со суммой и сроком оплаты.
- Обновление списка проектов каждые 15 секунд при открытой странице. Push-уведомлений пока нет.
- Документы доступны только владельцу проекта и команде. Загрузка PDF не создаёт новую юридическую Rechnung: администратор прикладывает готовый документ.
- Отзыв после завершения проекта, видимый только клиенту и команде.
- «Fliesenpause»: змейка на ремонтную тему, управление клавишами, свайпами и экранными кнопками, пауза, рекорд на устройстве.
- Иллюстративные стили в разделе Inspiration; это не реальные кейсы или отзывы.
- Web App Manifest для дальнейшего развития PWA. Офлайн-режим, service worker и доставка через App Store пока не реализованы.

## Проверки

```sh
npm run build
npm test
```

Интеграционный тест поднимает отдельный сервер с временной SQLite и проверяет регистрацию, вход, заявку, разграничение доступа, защиту от запросов другого origin, запрет SVG-загрузок, обновления, счета/PDF и отзывы. Тестовая база удаляется после завершения.

## Перед реальными клиентами

Это прототип, не готовая публичная система. Нужны проверенная Datenschutzerklärung/Impressum, пользовательский процесс удаления/экспорта данных, ограничение срока хранения, резервные копии, HTTPS, email verification и восстановление пароля, проверка загружаемых документов, мониторинг и нагрузочное тестирование. Не используйте реальные клиентские данные при демонстрации.

Запуск без демо: `npm start`. Для начального создания администратора задайте `NORDE_ADMIN_EMAIL` и `NORDE_ADMIN_PASSWORD` (минимум 12 символов) через безопасную конфигурацию процесса. Значения не пишите в репозиторий. Они применяются только при создании отсутствующего аккаунта; существующему пользователю роль и пароль не меняют. За HTTPS задайте `NORDE_SECURE_COOKIE=1`; внешнее прослушивание выбирается через `HOST`. Учитывайте, что секреты, подставляемые только сетевым proxy, не заменяют локальную переменную с паролем.

Apple/Google OAuth, Apple Pay через платёжного провайдера, почта, push, публичная лента с отдельным разрешением клиента, хранение файлов в объектном хранилище и нативная упаковка — следующие интеграции. Кнопка оплаты сейчас только объясняет отсутствие интеграции и не меняет статус счёта. Финансовых операций приложение не выполняет.

## Проект iOS для Xcode

Готовые исходники: `ios/Norde/Norde.xcodeproj`. Они включают SwiftUI/WKWebView и встроенную офлайн-демонстрацию, без зависимости от локального сервера. Откройте проект на Mac в Xcode 15+ и нажмите Run для симулятора iPhone. Полная инструкция: [START-HERE-RU.md](ios/Norde/START-HERE-RU.md).

Для обновления встроенного HTML используйте `npm run build:offline`. В офлайн-версии вход симулируется, пароли не сохраняются, заявки не уходят на сервер. Если браузер запрещает локальное хранилище для HTML-файла, демонстрация работает в памяти до закрытия окна. Офлайн-сценарии проверены в браузере без запросов к API; Swift/iOS-сборка здесь не проверена, поскольку Apple SDK и Xcode отсутствуют. Файл `.ipa` необходимо собирать и подписывать на Mac.

## Веб-версия 0.2: интерфейс приложения

При первом открытии — два минимальных экрана: приветствие и приглашение в Beratung. Можно начать конфигуратор или пропустить его. После этого — главный экран с одним основным действием/проектом и нижнее меню из пяти иконок: старт, проекты, Beratung, игра, настройки. У иконок есть доступные названия для VoiceOver. Повторное приветствие доступно в настройках; обычное обновление страницы его не повторяет. Данные существующей демоверсии сохраняются.

Кабинет команды, профиль, контакты и информация о демо находятся в настройках. Боковое меню, рекламный баннер, карточка цены и блоки сайта убраны с главного экрана. Цена базового пакета по-прежнему доступна на шаге выбора комплектации.

Актуальная автономная веб-версия генерируется командой `npm run build:offline` в `web-demo/index.html` и `dist/Norde-Demo.html`. Скрипт теперь **не обновляет Xcode/iOS-файлы**. Проект и ZIP iOS в репозитории остаются предыдущей версией; текущий этап разработки — только веб. Для GitHub Pages содержимое `web-demo/index.html` публикуется как `index.html` в ветке `gh-pages` с `.nojekyll`.
