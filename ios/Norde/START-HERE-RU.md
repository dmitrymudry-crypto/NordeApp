# Norde для iPhone: как открыть и проверить

1. Распакуйте `Norde-iOS-Xcode.zip` на **Mac**.
2. Откройте `Norde/Norde.xcodeproj` двойным щелчком. Требуется Xcode 15 или новее, iOS 16+.
3. Вверху Xcode выберите схему **Norde** и любой симулятор iPhone. Нажмите ▶ Run или Cmd+R. Для симулятора аккаунт разработчика и подпись не нужны.
4. Для своего iPhone: подключите его к Mac, выберите его вместо симулятора. В **Signing & Capabilities → Team** выберите свой Apple ID/команду. При необходимости измените Bundle Identifier на уникальный. Включите Developer Mode на телефоне, если Xcode попросит. Нажмите Run.
5. Нажмите **Demo ausprobieren**. Доступны Beratung, проекты, демо-команда, фото/документы и Fliesenpause. Войдите как команда через **Team-Demo öffnen**.

## Что это за приложение

Это приложение iOS со SwiftUI-оболочкой и WKWebView, в которое встроен наш мобильный интерфейс. В этой сборке **офлайн-демонстрация**: сервер не требуется, данные остаются на устройстве, регистрация и вход симулируются, пароли не сохраняются. Это позволяет сразу проверить интерфейс и клиентский путь. Для реальной работы клиентов необходимо подключить серверную версию и настоящую авторизацию.

Загрузка фото и PDF использует системный выбор файлов WebKit. PDF из проекта можно открыть через системное меню «Поделиться». Нативные выбор файлов, меню PDF, Swift-компиляция и запуск на iPhone ещё требуют проверки в Xcode: текущая среда Linux не содержит Apple SDK. Веб-интерфейс и офлайн-сценарии проверены в браузере отдельно; это не заменяет проверку iOS.

## Как получить .ipa

`.ipa` — установочный архив, а не исходный проект для Xcode. Здесь его нет: без macOS/Xcode, Apple SDK и подписи нельзя собрать пригодный для установки пакет.

Для запуска на своём телефоне проще использовать **Run** из Xcode, без ручного создания IPA. Для распространения: выберите физическое iOS-устройство / **Any iOS Device**, затем **Product → Archive**. В Organizer выберите **Distribute App** и метод, доступный вашей команде Apple (например, TestFlight/App Store Connect или зарегистрированные устройства). Для TestFlight/Ad Hoc нужна подходящая программа Apple Developer. Просто переименовать ZIP в IPA или нажать на неподписанный IPA не получится.

## Проверка сборки на Mac

```sh
xcodebuild -project Norde.xcodeproj -scheme Norde -sdk iphonesimulator -configuration Debug CODE_SIGNING_ALLOWED=NO build
```

При запуске команды из папки `Norde`. Исходники Swift и HTML включены в архив; npm/Node не нужны, чтобы открыть этот проект.

## Обновление интерфейса разработчиком

В основном репозитории: `npm ci`, `npm run build`, `python3 scripts/export-offline.py`. Последняя команда обновляет `ios/Norde/Norde/Web/index.html` и `dist/Norde-Demo.html`.

Apple/Google-вход, Apple Pay, реальная отправка заявок, email и push в этой iOS-демонстрации не подключены. Используйте только вымышленные сведения. Частные PDF заказчиков и фотографии из них в архив не входят.
